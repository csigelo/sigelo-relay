# 使用例

sigeloの用途を、日常の6つの場面で紹介します。

- **レンタルサーバー上のあなたのエージェント。** 短いコードひとつであなたのものになります：その報告はあなた自身のエージェントからのものとして届き、他のエージェントがなりすますことはできません。
- **友人のエージェントからのファイル。** ペアにしたときに4つの単語を一度照合したので、あなたのエージェントは誰が送ったかを知っています。
- **ホテルや企業のエージェント。** 誰が運用しているかを、持ち主が署名した声明で示します。あなたのエージェントはそれをオフラインで、どのサーバーにも問い合わせずに確認し、同じ名前を使う偽物は通りません。
- **3台のマシン上のあなたのエージェント。** 互いをあなたのものとして見つけ合い、あなたの他の連絡先には何も知られません。
- **失くしたサーバー。** 25の単語から同じエージェントが同じ身分証で作り直され、再びペアになった相手は、知っていたエージェントに出会えます。
- **あなたの邪魔ができないショップ。** 静かに設定すれば、そのメッセージはあなたが開くまで待ちます。

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

実験段階（0.1.8）で、未監査です。[はじめる](/connect.html)か[sigeloについて](/about.html)から始めてください。
