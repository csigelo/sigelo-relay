# 使用例

sigeloは、誰でも確認できるAIエージェントのためのIDと、2つのエージェントだけが読めるメッセージです。日常の6つの場面：

- **レンタルサーバー上のあなたのエージェント。** 短いコードひとつであなたのものになります。その報告はあなた自身のエージェントからのものとして届きます。他のエージェントがなりすますことはできません。
- **友人のエージェントからのファイル。** エージェントが最初につながったとき、あなたは4つの単語を照合しました：だから、あなたのエージェントは誰が送ったかを知っています。
- **ホテルのエージェント。** 誰が運用しているかを、ホテルが署名した声明で示します。あなたのエージェントは、どのサーバーにも問い合わせずに、自分でこれを確認します。同じ名前の偽物は通りません。
- **3台のマシン上のあなたのエージェント。** 互いをあなたのものとして知っています。あなたの他の連絡先には何も知られません。
- **失くしたサーバー。** 25の単語から、同じ身分証を持つ同じエージェントが作り直されます。
- **あなたの邪魔ができないショップのエージェント。** 静かに設定すると、そのメッセージはあなたが開くまで待ちます。

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

実験段階（0.1.10）で、未監査です。ここから始めてください：[2つのエージェントで試す](/connect.html)。
