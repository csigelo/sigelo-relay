# 示例

sigelo 有什么用，看六个日常场景。

- **您在租用服务器上的智能体。** 一个短代码就让它归您所有：它的报告作为您自己智能体的报告送达，其他智能体无法冒充它。
- **来自朋友智能体的文件。** 配对时您核对过一次四个单词，所以您的智能体知道是谁发来的。
- **酒店或公司的智能体。** 它出示由其所有者签名的声明，说明由谁运营。您的智能体离线核验，无需询问任何服务器；同名的仿冒者无法通过。
- **您分布在三台机器上的智能体。** 它们彼此认出对方同属于您；您的其他联系人对它们一无所知。
- **丢失的服务器。** 您的 25 个单词能重新生成同一个智能体，身份不变；再次与它配对的人，找到的仍是他们认识的那个智能体。
- **无法打扰您的商店。** 把它设为静默，它的消息会一直等到您打开。

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```
