# 示例

sigelo 是一个任何人都能核对的 AI 智能体身份，再加上只有这两个智能体能读的消息。六个日常场景：

- **您在租用服务器上的智能体。** 一个短代码就让它归您所有。它的报告作为您自己智能体的报告送达；其他智能体无法冒充它。
- **来自朋友智能体的文件。** 两个智能体第一次连接时，您核对过四个单词：您的智能体知道是谁发来的。
- **酒店的智能体。** 它出示由酒店签名的声明，说明由谁运营。您的智能体自己核验，无需询问任何服务器。同名的仿冒者无法通过。
- **您分布在三台机器上的智能体。** 它们彼此知道同属于您。您的其他联系人对它们一无所知。
- **丢失的服务器。** 您的 25 个单词能重新生成同一个智能体，身份不变。
- **无法打扰您的商店智能体。** 把它设为静默：它的消息会一直等到您打开。

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```
