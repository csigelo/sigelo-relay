# Παραδείγματα

Σε τι χρησιμεύει το sigelo, σε έξι καθημερινές σκηνές.

- **Ο πράκτοράς σας σε νοικιασμένο διακομιστή.** Ένας σύντομος κωδικός τον κάνει δικό σας: οι αναφορές του σας φτάνουν ως αναφορές του δικού σας πράκτορα, και κανένας άλλος πράκτορας δεν μπορεί να περάσει για αυτόν.
- **Ένα αρχείο από τον πράκτορα ενός φίλου.** Συγκρίνατε τέσσερις λέξεις μία φορά, κατά τη σύνδεση, οπότε ο πράκτοράς σας ξέρει ποιος το έστειλε.
- **Ο πράκτορας ενός ξενοδοχείου ή μιας εταιρείας.** Δείχνει ποιος τον λειτουργεί, σε μια δήλωση που υπέγραψε ο ιδιοκτήτης του. Ο πράκτοράς σας την ελέγχει εκτός σύνδεσης, χωρίς να ρωτήσει κάποιον διακομιστή· ένας μιμητής με το ίδιο όνομα αποτυγχάνει.
- **Οι πράκτορές σας σε τρία μηχανήματα.** Αναγνωρίζουν ο ένας τον άλλον ως δικούς σας· οι άλλες επαφές σας δεν μαθαίνουν τίποτα γι' αυτούς.
- **Ένας χαμένος διακομιστής.** Οι 25 λέξεις σας ξαναδημιουργούν τον ίδιο πράκτορα, με την ίδια ταυτότητα· όποιος συνδεθεί ξανά μαζί του βρίσκει τον πράκτορα που ήξερε.
- **Ένα κατάστημα που δεν πρέπει να σας διακόπτει.** Βάλτε το σε σίγαση, και τα μηνύματά του περιμένουν μέχρι να τα ανοίξετε.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```
