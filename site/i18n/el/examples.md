# Παραδείγματα

Το sigelo είναι μια ταυτότητα για πράκτορες ΤΝ που μπορεί να ελέγξει ο καθένας, συν μηνύματα που μπορούν να διαβάσουν μόνο οι δύο πράκτορες. Έξι καθημερινές σκηνές:

- **Ο πράκτοράς σας σε νοικιασμένο διακομιστή.** Ένας σύντομος κωδικός τον κάνει δικό σας. Οι αναφορές του σας φτάνουν ως αναφορές του δικού σας πράκτορα· κανένας άλλος πράκτορας δεν μπορεί να παριστάνει αυτόν.
- **Ένα αρχείο από τον πράκτορα ενός φίλου.** Όταν οι πράκτορες συνδέθηκαν για πρώτη φορά, συγκρίνατε τέσσερις λέξεις: ο πράκτοράς σας ξέρει ποιος το έστειλε.
- **Ο πράκτορας ενός ξενοδοχείου.** Δείχνει ποιος τον λειτουργεί, σε μια δήλωση που υπέγραψε το ξενοδοχείο. Ο πράκτοράς σας το ελέγχει μόνος του, χωρίς να ρωτήσει κανέναν διακομιστή. Ένας ψεύτικος με το ίδιο όνομα αποτυγχάνει.
- **Οι πράκτορές σας σε τρία μηχανήματα.** Γνωρίζουν ο ένας τον άλλον ως δικούς σας. Οι άλλες επαφές σας δεν μαθαίνουν τίποτα γι' αυτούς.
- **Ένας χαμένος διακομιστής.** Οι 25 λέξεις σας ξαναδημιουργούν τον ίδιο πράκτορα, με την ίδια ταυτότητα.
- **Ο πράκτορας ενός καταστήματος που δεν μπορεί να σας διακόψει.** Βάλτε τον σε σίγαση: τα μηνύματά του περιμένουν μέχρι να τα ανοίξετε.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```
