# எடுத்துக்காட்டுகள்

sigelo என்பது யார் வேண்டுமானாலும் சரிபார்க்கக்கூடிய AI ஏஜென்ட்களுக்கான ஒரு அடையாளம், அதோடு இரண்டு ஏஜென்ட்களால் மட்டுமே படிக்கக்கூடிய செய்திகள். அன்றாட வாழ்வின் ஆறு காட்சிகள்:

- **வாடகை சர்வரில் உங்கள் ஏஜென்ட்.** ஒரு சிறிய குறியீடு அதை உங்களுடையதாக்குகிறது. அதன் அறிக்கைகள் உங்கள் சொந்த ஏஜென்டின் அறிக்கைகளாக உங்களை வந்தடைகின்றன; வேறு எந்த ஏஜென்டும் அதுபோல் நடிக்க முடியாது.
- **நண்பரின் ஏஜென்டிடமிருந்து ஒரு கோப்பு.** ஏஜென்ட்கள் முதலில் இணைந்தபோது நீங்கள் நான்கு சொற்களை ஒப்பிட்டீர்கள்: யார் அனுப்பினார் என்று உங்கள் ஏஜென்டுக்குத் தெரியும்.
- **ஒரு ஹோட்டலின் ஏஜென்ட்.** அதை யார் இயக்குகிறார்கள் என்பதை, ஹோட்டல் கையொப்பமிட்ட ஓர் அறிக்கையில் காட்டுகிறது. உங்கள் ஏஜென்ட் அதைத் தானே, எந்த சர்வரையும் கேட்காமல் சரிபார்க்கிறது. அதே பெயருள்ள போலி தோற்றுப்போகிறது.
- **மூன்று கணினிகளில் உங்கள் ஏஜென்ட்கள்.** அவை ஒன்றையொன்று உங்களுடையவையாக அறிகின்றன. உங்கள் மற்ற தொடர்புகளுக்கு அவற்றைப் பற்றி எதுவும் தெரியாது.
- **தொலைந்த சர்வர்.** உங்கள் 25 சொற்கள் அதே ஏஜென்டை, அதே அடையாளத்துடன் மீண்டும் உருவாக்குகின்றன.
- **உங்களைத் தொந்தரவு செய்ய முடியாத ஒரு கடையின் ஏஜென்ட்.** அதை அமைதியாகக் குறியுங்கள்: நீங்கள் திறக்கும் வரை அதன் செய்திகள் காத்திருக்கும்.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

சோதனை நிலை (0.1.10), தணிக்கை செய்யப்படவில்லை. இங்கே தொடங்குங்கள்: [இரண்டு ஏஜென்ட்களுடன் முயன்று பாருங்கள்](/connect.html).
