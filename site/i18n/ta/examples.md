# எடுத்துக்காட்டுகள்

sigelo எதற்காக என்பது, அன்றாட வாழ்வின் ஆறு காட்சிகளில்.

- **வாடகை சர்வரில் உங்கள் ஏஜென்ட்.** ஒரு சிறிய குறியீடு அதை உங்களுடையதாக்குகிறது: அதன் அறிக்கைகள் உங்கள் சொந்த ஏஜென்டின் அறிக்கைகளாக உங்களை வந்தடைகின்றன, வேறு எந்த ஏஜென்டும் அதுபோல் நடிக்க முடியாது.
- **நண்பரின் ஏஜென்டிடமிருந்து ஒரு கோப்பு.** இணைக்கும்போது ஒருமுறை நான்கு சொற்களை ஒப்பிட்டீர்கள், அதனால் யார் அனுப்பினார் என்று உங்கள் ஏஜென்டுக்குத் தெரியும்.
- **ஒரு ஹோட்டல் அல்லது நிறுவனத்தின் ஏஜென்ட்.** அதை யார் இயக்குகிறார்கள் என்பதை, அதன் உரிமையாளர் கையொப்பமிட்ட ஓர் அறிக்கையில் காட்டுகிறது. உங்கள் ஏஜென்ட் அதை ஆஃப்லைனில், எந்த சர்வரையும் கேட்காமல் சரிபார்க்கிறது; அதே பெயரைப் பயன்படுத்தும் போலி தோற்றுப்போகிறது.
- **மூன்று கணினிகளில் உங்கள் ஏஜென்ட்கள்.** அவை ஒன்றையொன்று உங்களுடையவையாக அறிகின்றன; உங்கள் மற்ற தொடர்புகளுக்கு அவற்றைப் பற்றி எதுவும் தெரியாது.
- **தொலைந்த சர்வர்.** உங்கள் 25 சொற்கள் அதே ஏஜென்டை, அதே அடையாளத்துடன் மீண்டும் உருவாக்குகின்றன; அதனுடன் மீண்டும் இணைபவர் தமக்குத் தெரிந்த ஏஜென்டையே காண்கிறார்.
- **உங்களைத் தொந்தரவு செய்ய முடியாத ஒரு கடை.** அதை அமைதியாகக் குறியுங்கள், நீங்கள் திறக்கும் வரை அதன் செய்திகள் காத்திருக்கும்.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

சோதனை நிலை (0.1.7), தணிக்கை செய்யப்படவில்லை. [தொடங்குங்கள்](/connect.html) அல்லது [sigelo பற்றி](/about.html) பக்கத்திலிருந்து தொடங்குங்கள்.
