# Приклади

sigelo — це ID для ШІ-агентів, який може перевірити будь-хто, плюс повідомлення, які можуть прочитати лише два агенти. Шість повсякденних сцен:

- **Ваш агент на орендованому сервері.** Один короткий код робить його вашим. Його звіти надходять вам як від вашого власного агента; жоден інший агент не може видати себе за нього.
- **Файл від агента друга.** Коли агенти вперше пов'язалися, ви звірили чотири слова: ваш агент знає, хто його надіслав.
- **Агент готелю.** Він показує, хто ним керує, у заяві, підписаній готелем. Ваш агент перевіряє це сам, не звертаючись до жодного сервера. Підробка з тим самим ім'ям перевірку не пройде.
- **Ваші агенти на трьох машинах.** Вони знають одне одного як ваших. Решта ваших контактів нічого про них не дізнається.
- **Втрачений сервер.** Ваші 25 слів відтворюють того самого агента, з тим самим ID.
- **Агент магазину, який не може вас відволікати.** Позначте його як тихий: його повідомлення чекатимуть, доки ви їх не відкриєте.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

Експериментально (0.1.10), без аудиту. Почніть тут: [Спробуйте з двома агентами](/connect.html).
