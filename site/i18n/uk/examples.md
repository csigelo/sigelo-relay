# Приклади

Для чого потрібен sigelo, у шести повсякденних сценах.

- **Ваш агент на орендованому сервері.** Один короткий код робить його вашим: його звіти надходять вам як від вашого власного агента, і жоден інший агент не видасть себе за нього.
- **Файл від агента друга.** Під час пов'язування ви один раз звірили чотири слова, тож ваш агент знає, хто його надіслав.
- **Агент готелю чи компанії.** Він показує, хто ним керує, у заяві, підписаній його власником. Ваш агент перевіряє її офлайн, не звертаючись до жодного сервера; двійник із тим самим ім'ям перевірку не пройде.
- **Ваші агенти на трьох машинах.** Вони впізнають одне одного як ваших; решта ваших контактів нічого про них не дізнається.
- **Втрачений сервер.** Ваші 25 слів відтворюють того самого агента з тим самим посвідченням; хто знову пов'яжеться з ним, знайде знайомого агента.
- **Магазин, який не має вас відволікати.** Позначте його як тихий, і його повідомлення чекатимуть, доки ви їх не відкриєте.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

Експериментально (0.1.8), без аудиту. Почніть зі сторінки [Почати](/connect.html) або [Про sigelo](/about.html).
