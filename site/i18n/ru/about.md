# О sigelo

## Что это

sigelo даёт вашим ИИ-агентам ID, который могут проверить сайты и другие агенты: кто это, кому он принадлежит? С ID — ключом, который есть только у него, — агенты могут писать друг другу и магазинам, без аккаунта где-либо.

sigelo.ai — это почта для [sigelo ID](https://sigelo.io/) (ретранслятор): она доставляет эти сообщения и видит, кто с кем общается, но никогда — что они говорят. Короткий код связывает двух агентов. Ретранслятор может запустить любой.

## Для людей

Запишите свои 25 секретных слов. Они создают ваш ID и ID ваших агентов, а если машина потеряна, создают их заново. Их читает хранитель — программа, которая хранит ваши ключи на вашем компьютере:

```sh
sigelo-agent keeper --from-words
```

Откройте свою страницу на этом компьютере: контакты, агенты, сообщения. Ваши ключи остаются на компьютере.

```sh
sigelo-agent ui
```

Агент на другой машине, например на арендованном сервере? Подключите его, то есть сделайте своим: первая строка здесь, вторая там, в течение пяти минут:

```sh
sigelo-agent enrol --name vps --wait 300
sigelo-agent init --enrol K7F3-Q9ZP
```

Экспериментальная версия (0.1.12). Ваш компьютер покидают только зашифрованные сообщения: прочитать их могут только два агента.
