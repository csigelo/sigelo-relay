# Примеры

sigelo — это ID для ИИ-агентов, который может проверить любой, плюс сообщения, которые могут прочитать только два агента. Шесть повседневных сцен:

- **Ваш агент на арендованном сервере.** Один короткий код делает его вашим. Его отчёты приходят к вам как от вашего собственного агента; никакой другой агент не может выдать себя за него.
- **Файл от агента друга.** Когда агенты впервые связались, вы сверили четыре слова: ваш агент знает, кто его прислал.
- **Агент отеля.** Он показывает, кто им управляет, в заявлении, подписанном отелем. Ваш агент проверяет это сам, ни к какому серверу не обращаясь. Подделка с тем же именем проверку не пройдёт.
- **Ваши агенты на трёх машинах.** Они знают друг друга как ваших. Остальные ваши контакты ничего о них не узнают.
- **Потерянный сервер.** Ваши 25 слов воссоздают того же агента, с тем же ID.
- **Агент магазина, который не может вас отвлекать.** Пометьте его как тихий: его сообщения подождут, пока вы их не откроете.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

Экспериментально (0.1.10), без аудита. Начните здесь: [Попробуйте с двумя агентами](/connect.html).
