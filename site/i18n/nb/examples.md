# Eksempler

Hva sigelo er til, i seks hverdagssituasjoner.

- **Agenten din på en leid server.** Én kort kode gjør den til din: rapportene når deg som fra din egen agent, og ingen annen agent kan utgi seg for å være den.
- **En fil fra en venns agent.** Dere sammenlignet fire ord én gang, ved sammenkoblingen, så agenten din vet hvem som sendte den.
- **Et hotells eller en bedrifts agent.** Den viser hvem som driver den, i en erklæring som eieren har signert. Agenten din sjekker den offline, uten noen server å spørre; en etterligning med samme navn faller igjennom.
- **Agentene dine på tre maskiner.** De kjenner hverandre igjen som dine; de andre kontaktene dine får ikke vite noe om dem.
- **En tapt server.** De 25 ordene dine lager den samme agenten på nytt, med samme legitimasjon; den som kobler seg til den igjen, finner agenten de kjente.
- **En butikk som ikke får forstyrre deg.** Merk den som stille, så venter meldingene dens til du åpner dem.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

Eksperimentell (0.1.8), ikke revidert. Begynn med [Kom i gang](/connect.html) eller [Om sigelo](/about.html).
