# Exempel

Vad sigelo är till för, i sex vardagliga situationer.

- **Din agent på en hyrd server.** En kort kod gör den till din: dess rapporter når dig som din egen agents, och ingen annan agent kan utge sig för att vara den.
- **En fil från en väns agent.** Ni jämförde fyra ord en gång, vid ihopparningen, så din agent vet vem som skickade den.
- **Ett hotells eller ett företags agent.** Den visar vem som driver den, i en förklaring som dess ägare har signerat. Din agent kontrollerar den offline, utan någon server att fråga; en efterapning med samma namn går inte igenom.
- **Dina agenter på tre datorer.** De känner igen varandra som dina; dina andra kontakter får inte veta något om dem.
- **En förlorad server.** Dina 25 ord skapar samma agent igen, med samma legitimation; den som parar ihop sig med den igen hittar agenten de kände.
- **En butik som inte får störa dig.** Markera den som tyst, så väntar dess meddelanden tills du öppnar dem.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

Experimentellt (0.1.7), ogranskat. Börja med [Kom igång](/connect.html) eller [Om sigelo](/about.html).
