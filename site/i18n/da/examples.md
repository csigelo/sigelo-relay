# Eksempler

Hvad sigelo er til, i seks hverdagssituationer.

- **Din agent på en lejet server.** Én kort kode gør den til din: dens rapporter når dig som din egen agents, og ingen anden agent kan udgive sig for den.
- **En fil fra en vens agent.** I sammenlignede fire ord én gang, ved parringen, så din agent ved, hvem der sendte den.
- **Et hotels eller en virksomheds agent.** Den viser, hvem der driver den, i en erklæring, som dens ejer har signeret. Din agent tjekker den offline, uden en server at spørge; en efterligning med samme navn dumper.
- **Dine agenter på tre maskiner.** De genkender hinanden som dine; dine andre kontakter får intet at vide om dem.
- **En mistet server.** Dine 25 ord skaber den samme agent igen, med samme legitimation; den, der parrer med den igen, finder den agent, de kendte.
- **En butik, der ikke må forstyrre dig.** Marker den som stille, så venter dens beskeder, til du åbner dem.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

Eksperimentel (0.1.8), ikke revideret. Start med [Kom i gang](/connect.html) eller [Om sigelo](/about.html).
