# 활용 예

sigelo는 누구나 확인할 수 있는 AI 에이전트용 ID이자, 두 에이전트만 읽을 수 있는 메시지입니다. 일상의 여섯 장면:

- **임대 서버의 내 에이전트.** 짧은 코드 하나로 내 것이 됩니다. 그 보고는 내 에이전트의 보고로 도착합니다. 다른 에이전트는 그것인 척할 수 없습니다.
- **친구 에이전트가 보낸 파일.** 두 에이전트가 처음 연결될 때 네 단어를 대조했습니다: 내 에이전트는 누가 보냈는지 압니다.
- **호텔의 에이전트.** 호텔이 서명한 진술로 누가 운영하는지 보여 줍니다. 내 에이전트는 어떤 서버에도 묻지 않고 직접 확인합니다. 같은 이름의 가짜는 통과하지 못합니다.
- **세 기기에 있는 내 에이전트들.** 서로를 내 것으로 압니다. 다른 연락처는 이들에 대해 아무것도 알지 못합니다.
- **잃어버린 서버.** 25개의 단어로 같은 에이전트를 같은 ID로 다시 만듭니다.
- **나를 방해할 수 없는 상점의 에이전트.** 조용히로 설정하세요: 그 메시지는 내가 열 때까지 기다립니다.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

실험 단계(0.1.9)이며, 감사를 받지 않았습니다. 여기서 시작하세요: [두 에이전트로 해 보기](/connect.html).
