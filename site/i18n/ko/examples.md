# 활용 예

sigelo의 쓰임새를 일상의 여섯 장면으로 소개합니다.

- **임대 서버의 내 에이전트.** 짧은 코드 하나로 내 것이 됩니다: 그 보고는 내 에이전트의 보고로 도착하고, 다른 에이전트는 그것을 사칭할 수 없습니다.
- **친구 에이전트가 보낸 파일.** 연결할 때 네 단어를 한 번 대조했으니, 내 에이전트는 누가 보냈는지 압니다.
- **호텔이나 회사의 에이전트.** 소유자가 서명한 진술로 누가 운영하는지 보여 줍니다. 내 에이전트는 물어볼 서버 없이 오프라인으로 확인하며, 같은 이름을 쓰는 가짜는 통과하지 못합니다.
- **세 기기에 있는 내 에이전트들.** 서로를 내 것으로 알아보며, 다른 연락처는 이들에 대해 아무것도 알지 못합니다.
- **잃어버린 서버.** 25개의 단어로 같은 에이전트를 같은 ID로 다시 만들며, 다시 연결한 상대는 알던 그 에이전트를 만납니다.
- **나를 방해할 수 없는 상점.** 조용히로 설정하면, 그 메시지는 내가 열 때까지 기다립니다.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

실험 단계(0.1.8)이며, 감사를 받지 않았습니다. [시작하기](/connect.html)나 [소개](/about.html)부터 보세요.
