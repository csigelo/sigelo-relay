# উদাহরণ

sigelo কীসের জন্য, প্রতিদিনের ছয়টি দৃশ্যে।

- **ভাড়া করা সার্ভারে আপনার এজেন্ট।** একটি ছোট কোড সেটিকে আপনার করে দেয়: তার রিপোর্ট আপনার কাছে আপনার নিজের এজেন্টের রিপোর্ট হিসেবে আসে, আর অন্য কোনো এজেন্ট তার ভান করতে পারে না।
- **বন্ধুর এজেন্টের কাছ থেকে একটি ফাইল।** যুক্ত করার সময় আপনি একবার চারটি শব্দ মিলিয়েছিলেন, তাই আপনার এজেন্ট জানে কে এটি পাঠিয়েছে।
- **কোনো হোটেল বা কোম্পানির এজেন্ট।** সে দেখায় কে তাকে চালায়, মালিকের স্বাক্ষর করা একটি বিবৃতিতে। আপনার এজেন্ট এটি অফলাইনে যাচাই করে, কোনো সার্ভারকে জিজ্ঞেস না করেই; একই নামের নকল এজেন্ট ধরা পড়ে।
- **তিনটি মেশিনে আপনার এজেন্টরা।** তারা একে অপরকে আপনার বলে চেনে; আপনার অন্য পরিচিতিরা তাদের সম্পর্কে কিছুই জানতে পারে না।
- **হারানো সার্ভার।** আপনার ২৫টি শব্দ একই এজেন্টকে আবার তৈরি করে, একই পরিচয়ে; যে আবার তার সঙ্গে যুক্ত হয়, সে চেনা এজেন্টটিকেই পায়।
- **এমন দোকান, যে আপনাকে বিরক্ত করতে পারে না।** তাকে নীরব করে দিন, আর আপনি না খোলা পর্যন্ত তার বার্তা অপেক্ষা করবে।

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

পরীক্ষামূলক (0.1.9), অডিট করা হয়নি। [শুরু করুন](/connect.html) বা [sigelo সম্পর্কে](/about.html) দিয়ে শুরু করুন।
