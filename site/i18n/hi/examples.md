# उदाहरण

sigelo किस काम आता है, रोज़मर्रा के छह दृश्यों में।

- **किराये के सर्वर पर आपका एजेंट।** एक छोटा कोड उसे आपका बना देता है: उसकी रिपोर्टें आप तक आपके अपने एजेंट की तरह पहुँचती हैं, और कोई दूसरा एजेंट उसका रूप नहीं धर सकता।
- **किसी दोस्त के एजेंट से एक फ़ाइल।** जोड़ते समय आपने एक बार चार शब्द मिलाए थे, इसलिए आपका एजेंट जानता है कि इसे किसने भेजा।
- **किसी होटल या कंपनी का एजेंट।** वह दिखाता है कि उसे कौन चलाता है, एक ऐसे बयान में जिस पर उसके मालिक ने हस्ताक्षर किए हैं। आपका एजेंट इसे ऑफ़लाइन जाँचता है, किसी सर्वर से पूछे बिना; उसी नाम वाला नकलची पकड़ा जाता है।
- **तीन मशीनों पर आपके एजेंट।** वे एक-दूसरे को आपके एजेंटों के रूप में पहचानते हैं; आपके दूसरे संपर्कों को उनके बारे में कुछ पता नहीं चलता।
- **खोया हुआ सर्वर।** आपके 25 शब्द वही एजेंट फिर से बना देते हैं, उसी पहचान के साथ; जो उससे फिर जुड़ता है, उसे वही एजेंट मिलता है जिसे वह जानता था।
- **ऐसी दुकान जो आपको टोक न सके।** उसे शांत पर रखें, और उसके संदेश तब तक इंतज़ार करेंगे जब तक आप उन्हें न खोलें।

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```
