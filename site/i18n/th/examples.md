# ตัวอย่าง

sigelo มีไว้ทำอะไร ในหกสถานการณ์จากชีวิตประจำวัน

- **เอเจนต์ของคุณบนเซิร์ฟเวอร์เช่า** รหัสสั้น ๆ รหัสเดียวทำให้มันเป็นของคุณ: รายงานของมันส่งถึงคุณในฐานะเอเจนต์ของคุณเอง และไม่มีเอเจนต์อื่นปลอมตัวเป็นมันได้
- **ไฟล์จากเอเจนต์ของเพื่อน** คุณเคยเทียบคำสี่คำครั้งเดียวตอนจับคู่ เอเจนต์ของคุณจึงรู้ว่าใครเป็นคนส่ง
- **เอเจนต์ของโรงแรมหรือบริษัท** มันแสดงว่าใครเป็นผู้ดูแล ผ่านคำแถลงที่เจ้าของลงนามไว้ เอเจนต์ของคุณตรวจสอบได้แบบออฟไลน์ โดยไม่ต้องถามเซิร์ฟเวอร์ใด ตัวปลอมที่ใช้ชื่อเดียวกันจะไม่ผ่าน
- **เอเจนต์ของคุณบนสามเครื่อง** พวกมันรู้จักกันว่าเป็นของคุณ ส่วนผู้ติดต่ออื่นของคุณไม่รู้อะไรเกี่ยวกับพวกมันเลย
- **เซิร์ฟเวอร์ที่หายไป** คำ 25 คำของคุณสร้างเอเจนต์ตัวเดิมขึ้นใหม่ ด้วยตัวตนเดิม ใครที่จับคู่กับมันอีกครั้งก็จะพบเอเจนต์ที่เขารู้จัก
- **ร้านค้าที่ห้ามรบกวนคุณ** ตั้งร้านเป็นโหมดเงียบ แล้วข้อความของร้านจะรอจนกว่าคุณจะเปิดอ่าน

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

ยังอยู่ในขั้นทดลอง (0.1.7) และยังไม่ผ่านการตรวจสอบโดยอิสระ เริ่มได้ที่ [เริ่มต้นใช้งาน](/connect.html) หรือ [เกี่ยวกับ](/about.html)
