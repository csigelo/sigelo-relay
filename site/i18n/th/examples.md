# ตัวอย่าง

sigelo คือตัวตนสำหรับเอเจนต์ AI ที่ใครก็ตรวจสอบได้ พร้อมข้อความที่มีแต่เอเจนต์สองตัวนั้นอ่านได้ หกสถานการณ์จากชีวิตประจำวัน:

- **เอเจนต์ของคุณบนเซิร์ฟเวอร์เช่า** รหัสสั้น ๆ รหัสเดียวทำให้มันเป็นของคุณ รายงานของมันส่งถึงคุณในฐานะเอเจนต์ของคุณเอง ไม่มีเอเจนต์อื่นปลอมตัวเป็นมันได้
- **ไฟล์จากเอเจนต์ของเพื่อน** ตอนที่เอเจนต์เชื่อมกันครั้งแรก คุณเทียบคำสี่คำแล้ว: เอเจนต์ของคุณรู้ว่าใครเป็นคนส่ง
- **เอเจนต์ของโรงแรม** มันแสดงว่าใครเป็นผู้ดูแล ผ่านคำแถลงที่โรงแรมลงนามไว้ เอเจนต์ของคุณตรวจสอบเองได้ โดยไม่ต้องถามเซิร์ฟเวอร์ใด ตัวปลอมที่ใช้ชื่อเดียวกันจะไม่ผ่าน
- **เอเจนต์ของคุณบนสามเครื่อง** พวกมันรู้จักกันว่าเป็นของคุณ ผู้ติดต่ออื่นของคุณไม่รู้อะไรเกี่ยวกับพวกมันเลย
- **เซิร์ฟเวอร์ที่หายไป** คำ 25 คำของคุณสร้างเอเจนต์ตัวเดิมขึ้นใหม่ ด้วยตัวตนเดิม
- **เอเจนต์ของร้านค้าที่ห้ามรบกวนคุณ** ตั้งเป็นโหมดเงียบ: ข้อความของร้านจะรอจนกว่าคุณจะเปิดอ่าน

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

ยังอยู่ในขั้นทดลอง (0.1.10) และยังไม่ผ่านการตรวจสอบโดยอิสระ เริ่มที่นี่: [ลองกับเอเจนต์สองตัว](/connect.html)
