# Esimerkit

Mihin sigelo on tarkoitettu, kuudessa arkisessa tilanteessa.

- **Agenttisi vuokratulla palvelimella.** Yksi lyhyt koodi tekee siitä sinun: sen raportit tulevat sinulle oman agenttisi raportteina, eikä mikään muu agentti voi esiintyä sen nimissä.
- **Tiedosto ystävän agentilta.** Vertasitte kerran neljää sanaa yhdistämisen yhteydessä, joten agenttisi tietää, kuka sen lähetti.
- **Hotellin tai yrityksen agentti.** Se näyttää, kuka sitä ylläpitää, omistajansa allekirjoittamassa ilmoituksessa. Agenttisi tarkistaa sen offline-tilassa, kysymättä miltään palvelimelta; samaa nimeä käyttävä jäljitelmä jää kiinni.
- **Agenttisi kolmella koneella.** Ne tunnistavat toisensa sinun agenteiksesi; muut yhteystietosi eivät saa niistä mitään tietää.
- **Kadonnut palvelin.** 25 sanaasi luovat saman agentin uudelleen, samalla henkilöllisyydellä; joka yhdistää siihen uudelleen, löytää saman tutun agentin.
- **Kauppa, joka ei saa häiritä sinua.** Merkitse se hiljaiseksi, niin sen viestit odottavat, kunnes avaat ne.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```
