# 範例

sigelo 是一個任何人都能核對的 AI 代理身分，再加上只有這兩個代理讀得到的訊息。六個日常場景：

- **您在租用伺服器上的代理。** 一組短代碼就讓它歸您所有。它的報告會以您自己代理的身分送達；其他代理無法冒充它。
- **來自朋友代理的檔案。** 兩個代理第一次連接時，您核對過四個單字：您的代理知道是誰傳來的。
- **飯店的代理。** 它出示由飯店簽署的聲明，說明由誰營運。您的代理自己核對，不必詢問任何伺服器。同名的仿冒者無法通過。
- **您分布在三台機器上的代理。** 它們彼此知道同屬於您。您的其他聯絡人對它們一無所知。
- **遺失的伺服器。** 您的 25 個單字能重新產生同一個代理，身分不變。
- **無法打擾您的商店代理。** 把它設為靜音：它的訊息會一直等到您打開。

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

實驗階段（0.1.9），未經稽核。從這裡開始：[用兩個代理試試看](/connect.html)。
