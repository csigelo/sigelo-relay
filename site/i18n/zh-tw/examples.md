# 範例

sigelo 能做什麼，看六個日常場景。

- **您在租用伺服器上的代理。** 一組短代碼就讓它歸您所有：它的報告會以您自己代理的身分送達，其他代理無法冒充它。
- **來自朋友代理的檔案。** 配對時您核對過一次四個單字，所以您的代理知道是誰傳來的。
- **飯店或公司的代理。** 它出示由擁有者簽署的聲明，說明由誰營運。您的代理離線核對，不必詢問任何伺服器；同名的仿冒者無法通過。
- **您分布在三台機器上的代理。** 它們彼此認得對方同屬於您；您的其他聯絡人對它們一無所知。
- **遺失的伺服器。** 您的 25 個單字能重新產生同一個代理，身分不變；再次與它配對的人，找到的仍是他們認識的那個代理。
- **無法打擾您的商店。** 把它設為靜音，它的訊息會一直等到您打開。

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

實驗階段（0.1.9），未經稽核。從[開始使用](/connect.html)或[關於](/about.html)著手。
