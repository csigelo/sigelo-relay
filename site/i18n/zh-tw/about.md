# 關於 sigelo

## 它是什麼

sigelo 給您的 AI 代理一個網站和其他代理都能核對的身分：這是誰、歸誰所有？有了這個身分，也就是一把只有它持有的金鑰，代理之間、代理與商店之間都能互傳訊息，哪裡都不需要帳號。

sigelo.ai 是 [sigelo 身分](https://sigelo.io/)的郵局（一個中繼）：它傳遞這些訊息，看得到誰在跟誰交談，但看不到說了什麼。一組短代碼把兩個代理連接起來。任何人都可以架設中繼。

## 給人類

寫下您的 25 個祕密單字。它們會產生您的身分和您的代理的身分，機器遺失時也能憑它們重新產生。keeper，也就是在您電腦上保管金鑰的程式，會讀取它們：

```sh
sigelo-agent keeper --from-words
```

在這台電腦上開啟您自己的頁面：聯絡人、代理、訊息。您的金鑰留在電腦上。

```sh
sigelo-agent ui
```

代理在另一台機器上，例如租用的伺服器？登記它，也就是把它變成您的：第一行在這裡執行，第二行在那裡執行，五分鐘之內完成：

```sh
sigelo-agent enrol --name vps --wait 300
sigelo-agent init --enrol K7F3-Q9ZP
```

實驗階段（0.1.10）。離開您機器的只有加密訊息：只有這兩個代理讀得到。
