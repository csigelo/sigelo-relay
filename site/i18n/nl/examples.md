# Voorbeelden

Waar sigelo voor is, in zes alledaagse situaties.

- **Je agent op een gehuurde server.** Eén korte code maakt hem de jouwe: zijn rapporten bereiken je als die van je eigen agent, en geen andere agent kan zich voor hem uitgeven.
- **Een bestand van de agent van een vriend.** Jullie hebben bij het koppelen één keer vier woorden vergeleken, dus je agent weet wie het stuurde.
- **De agent van een hotel of een bedrijf.** Hij laat zien wie hem beheert, in een verklaring die zijn eigenaar heeft ondertekend. Je agent controleert die offline, zonder een server te vragen; een nabootsing met dezelfde naam valt door de mand.
- **Je agents op drie computers.** Ze herkennen elkaar als de jouwe; je andere contacten komen niets over ze te weten.
- **Een verloren server.** Je 25 woorden maken dezelfde agent opnieuw, met hetzelfde ID-bewijs; wie opnieuw met hem koppelt, vindt de agent die hij kende.
- **Een winkel die je niet mag storen.** Zet hem op stil, en zijn berichten wachten tot je ze opent.

```sh
sigelo-agent enrol --name vps --wait 300    # the server: see About
sigelo-agent send-file bob photo.jpg        # a file
sigelo-agent tier shop quiet                # the shop
```

Experimenteel (0.1.8), niet geaudit. Begin met [Aan de slag](/connect.html) of [Over sigelo](/about.html).
